# VisualForge AI Studio (кратко по-русски)

Локальная студия нейросетей для Windows: **Image** (редактирование и генерация картинок), **Video** (видео со звуком, речь персонажей,
экспорт в Instagram, микшер музыки), **Music** (песни и инструментал), **Text** (закрытый чат с картинками) и вкладка **Компоненты**.
Всё работает на вашем компьютере, без облака.

**Z-Image Turbo:** генерация по тексту за 8 шагов. **«Детализация 2K»** использует Real-ESRGAN x2 и повторный проход Z-Image за 5 шагов. Дополнительные Union/Tile открывают управление по контурам, ч/б или готовой карте, изменение области по маске и Tile-увеличение. Детализация и Tile перерисовывают фактуру и могут менять надписи и мелкие элементы. Обычные 2×/4× в режиме Prompt используют Real-ESRGAN. [Возможности, ограничения и проверки](docs/Z-Image-Turbo.md).

**Qwen Image Edit 2511:** правки по инструкции с 1–3 исходниками. Доступны стандартные 40 шагов и дополнительный Lightning на 4 шага. NSFW LoRA вынесена в отдельный переключатель; негативный промпт работает в стандартном профиле. Исходники приводятся примерно к 1 Мп без обрезки краёв. [Возможности, ограничения и проверки](docs/Qwen-Image-Edit-2511.md).

**Qwen Image 2.1:** нативная генерация и правки около 1 Мп или 2K, прозрачный PNG, подготовка удаления фона и до 10 исходников. Официальные расширители T2I/I2I — отдельные необязательные компоненты. Доступны явные 25/40 шагов; больше шагов не гарантирует лучшей композиции. [Возможности, ограничения и проверки](docs/Qwen-Image-2.1.md).

**FLUX.3 Klein:** генерация по тексту, правки по инструкции, 2–10 исходников и компоновка объектов по рамкам. Для текстовых режимов доступны нативные 2K/4K отдельно от Real-ESRGAN. Редактирование работает примерно в 1 Мп; 4K почти заполняет 16 ГБ VRAM и не гарантирует лучшей композиции. [Возможности, ограничения и проверки](docs/FLUX-3-Klein.md).

В настройках **«Язык интерфейса»** можно выбрать русский или English. Тексты меняются сразу, без перезагрузки страницы; выбор сохраняется. Введённые промпты, ответы моделей и работающие задачи сохраняются. [Устройство локализации](docs/VisualForge-Interface-Localization.md).

В истории Image, Video и Music кнопка «Удалить» после подтверждения удаляет запись, результат, связанные метаданные, временные файлы и отдельный лог задачи. Активную задачу сначала нужно остановить. В блоке «Данные генерации» доступны её тип, уникальный ID, дата старта и длительность; объект можно скопировать. Общие журналы движков сохраняются; подробности и ограничения — в [описании интерфейса](docs/VisualForge-Interface-Guide.md#deleting-a-generation).

В репозитории лежит только код, скрипты и документация. Программы (около 9,5 ГБ загрузки) и модели (около 234 ГБ) скачивает установщик
из оригинальных источников и проверяет каждый файл по SHA-256 из [App/config/component-catalog.json](App/config/component-catalog.json).

В настройках доступна **«История событий»** — единый журнал новых генераций и технических операций с фильтрами по типу и состоянию. Журналы разделов остаются отдельно. История начинает собираться после запуска обновлённой версии; аналитика кликов пока не собирается.

## Установка

Нужны: Windows 10/11, Git, видеокарта NVIDIA (настройки рассчитаны на 16 ГБ видеопамяти), интернет. Ставьте в **короткий путь**,
например `D:\VisualForge`.

```bat
git clone <адрес репозитория> D:\VisualForge
cd D:\VisualForge
Start-VisualForge.cmd
```

При первом запуске открывается меню установки:

- **программы** вокруг моделей (ComfyUI, окружения Video, Music, Text, ffmpeg, библиотеки) ставятся **всегда** - поэтому все вкладки
  остаются в студии;
- каждая **модель** - галочка: выберите только нужное (например, без видеомоделей). Если модели нет, вкладка так и скажет и подскажет
  вкладку **Компоненты**, где её можно скачать в любой момент, не перезапуская студию.

Без меню:

```bat
Setup-VisualForge.cmd --software-only            :: только программы, модели потом
Setup-VisualForge.cmd --preset light --yes        :: программы + небольшие модели каждого раздела
Setup-VisualForge.cmd --all --yes                 :: всё (около 244 ГБ)
Setup-VisualForge.cmd --models image.model.upscale,video.model.wan-ti2v-5b --yes
Setup-VisualForge.cmd --text-model gemma4:e4b     :: любая модель реестра Ollama для вкладки Text
Setup-VisualForge.cmd --import-ollama "имя:тег"   :: скопировать модель из вашей установленной Ollama
Setup-VisualForge.cmd --status | --verify | --help
```

Установка **докачивается**: оборвавшаяся загрузка продолжается с того же места, готовые файлы не качаются повторно, повторный запуск
чинит повреждённую установку. Системный Python, Ollama, драйверы и реестр не затрагиваются: всё лежит внутри папки VisualForge.

## Модели: включение и удаление

Откройте шестерёнку справа сверху → **Компоненты**. «Отключить» сохраняет файлы, но запрещает использовать модель; «Включить» возвращает её в работу. Переключатели хранятся в `UserData`, отдельно от исходников. Скачанную заново модель можно включить здесь же.

«Удалить модель…» сначала показывает состав удаления и выдерживает 10 секунд. Затем введите **REMOVE** и нажмите «Удалить безвозвратно». Удаляются файлы выбранной модели и её собственные кеши; общие зависимости и Ollama-blobs других моделей сохраняются. Чаты, промпты, результаты, внешние папки и системная Ollama не удаляются. Во время генерации или установки изменение моделей блокируется.

## GitHub: только лёгкие исходники

`Models`, `Runtime`, `UserData`, кеши, результаты, архивы запросов, временные файлы и установленные EXE остаются на компьютере. Правила действуют и для таких папок внутри каталогов исходников. Обычный предел одного исходного файла — 2 МиБ; суммарный предел истории публикации — 10 ГБ. Разрешены только проверенные значки приложения.

После клонирования включите локальную защиту:

```bat
git config core.hooksPath .githooks
```

Pre-commit проверяет содержимое индекса Git, pre-push — именно отправляемую историю, включая уже удалённые файлы. В GitHub добавлена проверка source-only. `.gitignore` не действует на уже отслеживаемые файлы, а локальные hooks можно намеренно отключить; поэтому для публикации используйте проверяемую команду ниже.

Из рабочей portable-папки (в том числе на H:) после настройки `origin`:

```bat
python tools/publish_source.py --prepare
python tools/publish_source.py --push
```

Публикуется только `public-main` в удалённую `main`: тот же код, отдельная публичная история без частных веток и тегов. Повторная публикация продолжает уже существующую публичную историю и не использует force push. Модели и программы новый пользователь получает через установщик.

У скачиваемых файлов есть HTTPS-источники издателей и закреплённые SHA-256. Где доступны альтернативные адреса тех же файлов, установщик перебирает их; неверный хеш также переключает источник. Некоторые адреса используют общую инфраструктуру одного издателя. LTX требует принятия условий и доступа Hugging Face; резервный адрес этого требования не обходит. Локальные пользовательские Ollama-сборки без публичного адреса переносятся импортом.

## Важно про лицензии

У собственного кода студии пока **нет файла лицензии** (все права сохранены, пока автор не выберет лицензию). Сторонние программы и
модели имеют свои лицензии: [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md). Отдельно проверьте **территориальное ограничение
лицензии MiniMax H3** (модель FreeVideo H3): её текст исключает из зоны действия Европейский союз, Великобританию, Южную Корею и США.
Часть моделей - только для некоммерческого использования, а некоторые сообщественные квантизации не имеют фильтров.

Подробное описание возможностей и устройства: [README.md](README.md) и [docs](docs).


Если зависимость недоступна по всем адресам, студия открывает окно на 30 секунд: укажите другую прямую ссылку или скачанный файл той же версии. Размер и SHA-256 проверяются. Без ответа файл пропускается; остальные загрузки продолжаются. Неполные компоненты не запускаются, зависимые модели остаются недоступными. Повторное включение модели или «Установить / восстановить» заново проверяет её зависимости и повторяет запрос.

Небольшие программные зависимости до 300 МБ можно размещать в GitHub Releases; подготовка описана в `docs/VisualForge-Component-Setup.md`. Модели, кеши и пользовательские данные в этот набор не входят.
