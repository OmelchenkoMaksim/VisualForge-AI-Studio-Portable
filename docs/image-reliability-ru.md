# VisualForge 2026.10.24-image.2

Обновление надёжности Image перед интеграцией Video.

## Изменения

- Поле seed: пустое значение сохраняет прежний случайный выбор; доступны повтор последнего seed и seed из истории.
- Черновик промпта и выбранный seed сохраняются локально в профиле браузера.
- История последних 100 завершённых заданий хранит параметры и ссылки на уже сохранённые файлы. Интерфейс показывает последние 20 записей без автоматической загрузки больших изображений. Файлы результатов при вытеснении записей не удаляются.
- Сохранённые результаты и конечный статус отмены доступны после перезапуска bridge, даже когда ComfyUI недоступен.
- Повторный опрос отменённого задания больше не возвращает его в состояние «в очереди». Фоновое ожидание автосохранения прекращается после подтверждённой отмены.
- Внутренние пути результатов записываются относительно portable-корня; выбранные внешние абсолютные пути сохраняются.
- Повреждённая история сохраняется без перезаписи и не блокирует генерацию. Ошибка записи истории не отменяет сохранение результата.
- Добавлены точные пояснения о прозрачности и закрытии окна. При активной задаче страница запрашивает стандартную защиту браузера от ухода.

Модели, workflows, sampler, число шагов, CUDA, PyTorch, embedded Python и launcher не менялись. Заявления об ускорении sampling не делаются. История позволяет читать результаты непосредственно из папки сохранения без повторного обращения к ComfyUI.

## Проверка

Проверки и фактические результаты записаны в `validation.json` пакета. Реальная генерация с seed 2026102401 в staging дала тот же граф и побитово тот же PNG, что исходная установленная версия. Дополнительный запуск при проверке ухода со страницы также завершился; он не считается отменённым.

Отмена проверялась на отдельной собственной задаче: конечная запись появилась без опроса статуса страницей, повторные запросы и перезапуск сохранили `cancelled`. История и PNG успешно читались через HTTP с заведомо недоступным тестовым backend.

Staging bridge работал на 127.0.0.1:8289, используя неизменённый установленный Image ComfyUI на 127.0.0.1:8188. Полная повторная матрица GPU для всех шести режимов не выполнялась. Запуск нового пакета через EXE в production ожидает отдельного согласования.

## Установка

Пакет рассчитан только на проверенный `2026.10.24-layout.1`. Скрипт проверяет хеш установленного манифеста и каждого заменяемого файла, затем хеши payload. Несовпадение останавливает установку до изменения файлов.

По умолчанию выполняется только проверка:

```powershell
.\Update-ImageReliability.ps1 -Root '<папка установки VisualForge>' -Mode Plan
```

После отдельного согласования обновления production необходимо закрыть основное окно VisualForge. Скрипт не завершает процессы и отказывается обновлять работающую установку.

```powershell
.\Update-ImageReliability.ps1 -Root '<папка установки VisualForge>' -Mode Apply
```

В `Support/Backups` создаётся новая проверенная копия всех затронутых прежних файлов и установленного манифеста. Скрипт не заменяет Runtime, Models, EXE и UserData. Он также устанавливает отчёт проверки в `Support/Diagnostics/ImageReliabilityValidation.json`.

## Откат

Скрипт после установки выводит точный путь нового backup. Для отката следует закрыть VisualForge и указать этот абсолютный путь:

```powershell
.\Update-ImageReliability.ps1 -Root '<папка установки VisualForge>' -Mode Rollback -BackupDirectory 'ТОЧНЫЙ_АБСОЛЮТНЫЙ_ПУТЬ_ИЗ_РЕЗУЛЬТАТА_УСТАНОВКИ'
```

Сначала проверяются хеши текущих и резервных файлов. Изменённые после установки файлы не перезаписываются. Восстанавливаются прежние файлы и прежний манифест; удаляются только новые файлы этого конкретного обновления с совпадающими хешами. Backup и UserData сохраняются.

## Ограничения

- Автоматическое восстановление управления выполняющимся заданием после принудительного обновления страницы не добавлено; стандартное предупреждение браузера зависит от браузера и наличия пользовательского взаимодействия.
- 2511 выдаёт RGB. Формат RGBA у 2.1 не гарантирует сохранение прозрачности исходника. Маска исходника не восстанавливается автоматически.
- Избранные промпты остаются в прежнем архиве. Новая история не импортирует автоматически старые изображения и не копирует их в новую папку.
- Source-репозиторий восстановлен из установленного App; утраченная историческая Git-цепочка не реконструировалась. Локальные commit отражают исходный снимок и это обновление.
- Video пока не интегрирован. Новых компонентов за разработку этого обновления не скачивалось.
